# DSA Project 2 - Warehouse Pathfinding

A warehouse map visualizer that compares **Dijkstra's** and **A\*** pathfinding algorithms using SFML.

## Requirements

- CMake 3.28+
- A C++20 compatible compiler
- Internet connection (CMake will automatically download SFML 3.0.2)

## Build & Run

```bash
cmake -B build
cmake --build build
./build/bin/main
```
